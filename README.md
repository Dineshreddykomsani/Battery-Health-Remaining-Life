#  Battery Health & Remaining Useful Life Prediction

## Project Description
This project predicts the Remaining Useful Life (RUL) of a battery using Machine Learning based on historical performance data. It helps in predictive maintenance and battery health monitoring.

##  Features
- ML-based battery life prediction
- Flask web application
- Real-time user input
- Deployed online using Render

##  Tech Stack
- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Flask
- HTML, CSS

## How to Run
pip install -r requirements.txt  
python app.py
